# Подключение базы данных к проекту в Vercel

## Текущая ситуация

Вы видите интерфейс "Connect to a Database" и базу данных **`vodeco_data`** уже создана.

## Шаги для подключения

### 1. Нажмите кнопку "Connect" на базе данных `vodeco_data`

- В интерфейсе найдите карточку с базой данных **`vodeco_data`**
- Нажмите кнопку **"Connect"** справа от базы данных

### 2. Vercel автоматически добавит DATABASE_URL

После нажатия "Connect":
- ✅ Vercel автоматически добавит переменную `DATABASE_URL` в Environment Variables
- ✅ База данных будет подключена к вашему проекту
- ✅ Вы будете перенаправлены обратно в проект

### 3. Проверьте, что DATABASE_URL добавлен

1. Перейдите в **Settings** → **Environment Variables**
2. Убедитесь, что есть переменная `DATABASE_URL`
3. Значение должно начинаться с `postgresql://`

### 4. Запустите деплой

После подключения базы данных:

1. Перейдите в **Deployments**
2. Нажмите **"Redeploy"** на последнем деплое
3. Или сделайте новый commit в GitHub (Vercel автоматически задеплоит)

### 5. После успешного деплоя - примените миграции

**Вариант 1: Через Vercel CLI (рекомендуется)**

```bash
# Установите Vercel CLI (если еще не установлен)
npm install -g vercel

# Войдите в Vercel
vercel login

# Подключите проект
vercel link

# Скачайте переменные окружения
vercel env pull .env.local

# Примените миграции
npx prisma migrate deploy
```

**Вариант 2: Использовать db push (для MVP, проще)**

```bash
vercel env pull .env.local
npx prisma db push
```
