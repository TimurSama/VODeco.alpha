# API ключи и мобильная ориентация

## 🔑 API ключи: Vercel Dashboard

### ⚠️ ВАЖНО: Все API ключи настраиваются ТОЛЬКО в Vercel!

**НЕ добавляйте API ключи в код приложения!** Все секреты настраиваются через Vercel Dashboard.

### Почему это безопасно:

✅ **Ключи хранятся в зашифрованном виде**  
✅ **Не попадают в Git репозиторий**  
✅ **Доступны только на сервере** (не в браузере)  
✅ **Можно менять без изменения кода**

### Как добавить API ключ:

1. Откройте **Vercel Dashboard** → ваш проект
2. Перейдите в **Settings** → **Environment Variables**
3. Нажмите **"Add New"**
4. Введите:
   - **Key**: `NEWS_API_KEY` (или другой ключ)
   - **Value**: ваш API ключ
   - **Environment**: Production, Preview, Development
5. Нажмите **Save**
6. **Перезапустите деплой** (Redeploy)

### Доступ к переменным в коде:

```typescript
// В серверном коде (API routes)
const apiKey = process.env.NEWS_API_KEY;

// В клиентском коде (только NEXT_PUBLIC_*)
const publicUrl = process.env.NEXT_PUBLIC_APP_URL;
```

**Важно:** Переменные с префиксом `NEXT_PUBLIC_` доступны в браузере. Используйте их только для публичных данных!

## 📱 Мобильная ориентация

### ✅ Подтверждение: Mobile-First подход

**Да, приложение ориентировано на мобильные устройства с адаптацией под десктоп!**

### Что реализовано:

1. **Viewport настроен** для мобильных устройств
2. **Mobile-first CSS** - базовые стили для мобильных, затем адаптация для десктопа
3. **Touch-жесты** - swipe для открытия меню (как в Telegram)
4. **Telegram Mini App** оптимизация
5. **Адаптивные компоненты** - Header, Sidebar, карточки

### Breakpoints:

```css
/* Mobile First */
- Базовые стили: мобильные (< 640px) ← ПРИОРИТЕТ
- sm: 640px+ (планшеты)
- md: 768px+ (планшеты landscape)
- lg: 1024px+ (ноутбуки)
- xl: 1280px+ (десктопы) ← АДАПТАЦИЯ
```

### Особенности:

- ✅ **Бургер-меню** вместо полного меню на мобильных
- ✅ **Swipe-жесты** для навигации
- ✅ **Большие touch-таргеты** для удобства
- ✅ **Адаптивные отступы** и размеры шрифтов
- ✅ **Оптимизация для вертикальной ориентации**
