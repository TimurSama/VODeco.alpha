## 🔑 Обязательные API ключи

### 1. DATABASE_URL (автоматически)

**Статус:** ✅ Автоматически создаётся при добавлении PostgreSQL в Vercel

**Как получить:**
1. Vercel Dashboard → ваш проект → **Storage**
2. Нажмите **"Create Database"**
3. Выберите **Postgres**
4. Создайте базу данных
5. Vercel автоматически добавит `DATABASE_URL` в Environment Variables

**Проверка:**
- Должен быть автоматически добавлен в Vercel
- Формат: `postgresql://user:password@host:port/database`

## ⚙️ Опциональные API ключи

### 2. NEWS_API_KEY (рекомендуется)

**Статус:** ⚙️ Опционально, но рекомендуется для лучшего контента

**Что даёт:**
- Доступ к миллионам новостных статей
- Фильтрация по темам (water, ecology, environment)
- Более актуальные новости

**Как получить:**

1. **Зарегистрируйтесь на NewsAPI:**
   - Откройте [newsapi.org](https://newsapi.org)
   - Нажмите **"Get API Key"**
   - Заполните форму регистрации

2. **Получите бесплатный ключ:**
   - После регистрации вы получите API ключ
   - Бесплатный план: 100 запросов/день
   - Для MVP этого достаточно

3. **Скопируйте ключ:**
   - Формат: `1234567890abcdef1234567890abcdef`
   - Сохраните ключ в безопасном месте

**Добавление в Vercel:**
```
Key: NEWS_API_KEY
Value: [ваш ключ от newsapi.org]
Environment: Production, Preview, Development
```

**Без ключа:**
- Приложение будет работать
- Используется RSS fallback (Google News, UN, Greenpeace и др.)
- Меньше новостей, но функциональность сохраняется

---

### 3. JWT_SECRET (для продакшена)

**Статус:** ⚙️ Опционально для тестовой версии, обязательно для продакшена

**Что даёт:**
- Безопасная аутентификация пользователей
- Защита сессий

**Как получить:**

**Вариант 1: Сгенерировать случайную строку**
```bash
# В терминале (Linux/Mac)
openssl rand -hex 32

# Или онлайн генератор
# https://www.random.org/strings/
```

**Вариант 2: Использовать дефолтный (только для теста)**
- Для тестовой версии приложение использует дефолтный ключ
- **НЕ используйте дефолтный для продакшена!**

**Добавление в Vercel:**
```
Key: JWT_SECRET
Value: [случайная строка, минимум 32 символа]
Environment: Production, Preview, Development
```

**Пример значения:**
```
ba0a89f5cdb813af31576f3889c601e6e435922c911f157faa58076e04294e51
```

---

### 4. TELEGRAM_BOT_TOKEN (для Telegram Mini App)

**Статус:** ⚙️ Опционально, только если используете Telegram Mini App

**Что даёт:**
- Интеграция с Telegram
- Автоматическая аутентификация через Telegram
- Доступ к Telegram WebApp API

**Как получить:**

1. **Откройте Telegram:**
   - Найдите бота [@BotFather](https://t.me/BotFather)
   - Или откройте: `https://t.me/BotFather`

2. **Создайте бота:**
   - Отправьте команду `/newbot`
   - Следуйте инструкциям:
     - Введите имя бота (например: "VODeco Bot")
     - Введите username бота (например: "vodeco_bot")

3. **Получите токен:**
   - BotFather отправит вам токен
   - Формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`
   - **Сохраните токен!** Он показывается только один раз

4. **Настройте WebApp:**
   - Отправьте `/newapp` в BotFather
   - Выберите вашего бота
   - Укажите URL вашего приложения: `https://ваш-проект.vercel.app`

**Добавление в Vercel:**
```
Key: TELEGRAM_BOT_TOKEN
Value: [токен от @BotFather]
Environment: Production, Preview, Development
```

**Без токена:**
- Приложение будет работать как обычный веб-сайт
- Telegram-специфичные функции не будут доступны

---

### 5. NEXT_PUBLIC_APP_URL (опционально)

**Статус:** ⚙️ Опционально, можно добавить после деплоя

**Что даёт:**
- Правильные ссылки в email-уведомлениях
- Корректные реферальные ссылки
- Правильные мета-теги для социальных сетей

**Как получить:**
- После первого деплоя Vercel создаст URL
- Формат: `https://ваш-проект.vercel.app`
- Или используйте свой домен

**Добавление в Vercel:**
```
Key: NEXT_PUBLIC_APP_URL
Value: https://ваш-проект.vercel.app
Environment: Production, Preview, Development
```

## 🌐 Внешние API (без ключей)

Эти API работают **без ключей** и уже интегрированы:

### 1. OpenStreetMap Overpass API ✅

**URL:** `https://overpass-api.de/api/interpreter`

**Что даёт:**
- Географические данные о водных объектах
- Реки, озёра, каналы
- Глобальное покрытие

**Статус:** ✅ Полностью интегрировано  
**Ключ не требуется:** ✅ Работает без ключа  
**Rate Limit:** Умеренный (не требует регистрации)

**Использование:**
- Автоматически используется при запросе `/api/water-resources?external=true`
- Кэш: 1 час

### 2. World Bank Water Data API ✅

**URL:** `https://api.worldbank.org/v2/country/{country}/indicator/{indicator}`

**Что даёт:**
- Доступ к безопасной воде по странам
- Статистика санитарии
- Водные ресурсы на душу населения
- Уровень водного стресса

**Индикаторы:**
- `SH.H2O.SAFE.ZS` - Доступ к безопасной воде
- `SH.STA.BASS.ZS` - Доступ к базовой санитарии
- `ER.H2O.INTR.PC` - Водные ресурсы на душу населения
- `ER.H2O.FWTL.ZS` - Уровень водного стресса

**Статус:** ✅ Полностью интегрировано  
**Ключ не требуется:** ✅ Работает без ключа  
**Rate Limit:** Умеренный

**Использование:**
- Автоматически используется при запросе `/api/water-resources?external=true`
- Кэш: 1 час

**Статус:** ✅ Полностью интегрировано  
**Ключ не требуется:** ✅ Работает без ключа  
**Coverage:** США  
**Rate Limit:** Умеренный

**Использование:**
- Автоматически используется при запросе `/api/water-resources?external=true`

- Достаточно для MVP

### Шаг 2: JWT_SECRET (для продакшена)

**Генерация ключа:**

**Linux/Mac:**
```bash
openssl rand -hex 32
```

**Windows PowerShell:**
```powershell
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 64 | ForEach-Object {[char]$_})
```

**Онлайн генератор:**
- [random.org](https://www.random.org/strings/)
- Выберите: 64 символа, буквы и цифры

**Требования:**
- Минимум 32 символа
- Рекомендуется 64 символа
- Случайная строка (не используйте простые слова)

## ⚙️ Настройка в Vercel

### Пошаговая инструкция:

1. **Откройте Vercel Dashboard**
   - Зайдите на [vercel.com](https://vercel.com)
   - Войдите в аккаунт

2. **Выберите проект**
   - Найдите ваш проект
   - Кликните на него

3. **Откройте Settings**
   - Вверху справа нажмите **"Settings"**
   - В меню слева выберите **"Environment Variables"**

4. **Добавьте переменные**

   Для каждой переменной:
   - Нажмите **"Add New"**
   - Введите **Key** (например, `NEWS_API_KEY`)
   - Введите **Value** (ваш API ключ)
   - Выберите **Environment**:
     - ✅ **Production** - для продакшена
     - ✅ **Preview** - для preview деплоев
     - ✅ **Development** - для локальной разработки
     - Или выберите **"All"** для всех окружений
   - Нажмите **"Save"**

5. **Создайте PostgreSQL базу данных** (если ещё не создана)
   - Vercel Dashboard → **Storage** → **Create Database**
   - Выберите **Postgres**
   - Создайте базу данных
   - Vercel автоматически добавит `DATABASE_URL`

6. **Перезапустите деплой**
   - Deployments → последний деплой → **"..."** → **"Redeploy"**
   - Или сделайте новый commit в GitHub

## ✅ Проверка работы

### 1. Проверка переменных окружения

**В Vercel Dashboard:**
1. Settings → Environment Variables
2. Убедитесь, что все переменные добавлены
3. Проверьте, что выбраны правильные Environment

**В логах:**
1. Vercel Dashboard → Functions → Logs
2. Не должно быть ошибок про отсутствующие переменные
3. Если есть ошибки - проверьте названия ключей

---

### 2. Проверка API

**Water Resources:**
```bash
# Без внешних API
curl https://ваш-проект.vercel.app/api/water-resources

# С внешними API
curl https://ваш-проект.vercel.app/api/water-resources?external=true
```

**News:**
```bash
# Без NewsAPI (только RSS)
curl https://ваш-проект.vercel.app/api/news

# С NewsAPI (если добавлен ключ)
curl https://ваш-проект.vercel.app/api/news?api=true
```

**Projects:**
```bash
curl https://ваш-проект.vercel.app/api/projects
```

---

### 3. Проверка базы данных

**В Vercel Dashboard:**
1. Storage → ваша база данных
2. Проверьте, что база данных активна
3. Проверьте подключение

**Миграции:**
```bash
# Локально (если нужно)
npx prisma migrate deploy
```

**В Vercel:**
- Миграции выполняются автоматически при деплое (см. `vercel.json`)

## ❓ FAQ

**Q: Нужно ли добавлять все API ключи сразу?**  
A: Нет, достаточно `DATABASE_URL`. Остальные можно добавить позже.

**Q: Что если я не добавлю NEWS_API_KEY?**  
A: Приложение будет работать, используя RSS источники (UN, Greenpeace и др.).

**Q: Можно ли использовать дефолтный JWT_SECRET?**  
A: Только для тестовой версии. Для продакшена обязательно сгенерируйте свой.

**Q: Как проверить, что API ключи работают?**  
A: Проверьте логи в Vercel Dashboard → Functions → Logs.

**Q: Что делать, если API не работает?**  
A: Проверьте название ключа, значение, и перезапустите деплой.
