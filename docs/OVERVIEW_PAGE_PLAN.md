# Детальный план страницы Overview (Презентация VODeco)

## Общая концепция

Интерактивная презентационная страница с плавными переходами между экранами, 3D-глобусом, анимированными счетчиками, попап-окнами с детальной информацией. Максимально визуализированная и интерактивная, а не просто текст с анимациями.

---

## ЭКРАН 1: Введение и общее описание проекта

### Визуальная композиция:
- **Фон**: Темный градиент (ocean-deep) с легкими водными эффектами
- **Центр экрана**: Текстовый блок с заголовком и описанием VODeco
- **Правый нижний угол**: Вращающийся 3D-глобус (уменьшенный, ~300x300px)
- **Кнопка CTA**: "Изучить проект" / "Начать путешествие" (внизу по центру)

### Контент:
- **Заголовок**: "VODeco - Децентрализованная экосистема управления водными ресурсами"
- **Подзаголовок**: "Токенизация участия и демократизация управления водными активами через IoT + AI + Blockchain"
- **Описание**: Краткое введение (2-3 предложения) о миссии проекта
- **SDG Badges**: Иконки соответствия ЦУР ООН (6, 9, 11, 13, 16)

### Анимации:
- Плавное появление текста (fade-in + slide-up)
- Глобус медленно вращается (автоматически)
- Кнопка пульсирует легким свечением
- При наведении на SDG badges - показывается краткое описание

### Интерактив:
- Клик на глобус → переход к экрану 2
- Клик на кнопку "Изучить" → переход к экрану 2

## ЭКРАН 3: Решение - Систематизированное экосистемное объединение

### Визуальная композиция:
- **Фон**: Градиент от темного к светлому (символизирует решение)
- **Центр**: Схема экосистемы с блоками

### Блоки экосистемы:

#### 1. Объекты (Objects)
- **Иконка**: Водные объекты (реки, озера, станции)
- **Описание**: Физические водные объекты и инфраструктура
- **Попап**: 
  - Типы объектов (реки, озера, насосные станции, очистные)
  - Количество объектов в системе
  - Географическое распределение
  - Статус мониторинга

#### 2. Субъекты (Subjects)
- **Иконка**: Люди/организации
- **Описание**: Участники экосистемы
- **Попап**:
  - Роли (активисты, исследователи, инвесторы, государства, НКО)
  - Количество участников по ролям
  - Географическое распределение
  - Активность участников

#### 3. Данные (Data)
- **Иконка**: IoT датчики / спутники
- **Описание**: Источники данных о воде
- **Попап**:
  - Типы данных (IoT, спутники, лаборатории, citizen science)
  - Объем данных
  - Частота обновления
  - Верификация данных

#### 4. Блокчейн (Blockchain)
- **Иконка**: Цепочка блоков
- **Описание**: Неизменяемое хранение и верификация
- **Попап**:
  - Технология (TON Network)
  - Хэширование данных
  - Смарт-контракты
  - Прозрачность

#### 5. Экономика (Economy)
- **Иконка**: Токены / монеты
- **Описание**: Токеномика и инвестиционные механизмы
- **Попап**:
  - VOD credits / WTR токены
  - Стейкинг
  - Инвестиционные пулы
  - Награды и стимулы

#### 6. Управление (Governance)
- **Иконка**: DAO символ
- **Описание**: Децентрализованное управление
- **Попап**:
  - DAO структура
  - Голосование
  - Предложения
  - Аудит

### Визуализация связей:
- Анимированные линии между блоками
- При клике на блок → подсветка связанных блоков
- Показ потока данных/ценности между блоками

### Анимация:
- Блоки появляются последовательно
- Линии рисуются анимированно
- Легкое пульсирование активных блоков

- **Попап**:
  - Механика data-mint
  - Формула W_m3
  - Верификация данных
  - Стабилизация цены

#### 3. Эмиссия

  - Оракулы и валидаторы

#### 4. Фазы эволюции
- **Фаза 0**: Pre-sensor Credits
- **Фаза 1**: Access & Participation

- **Фаза 3**: Data Anchoring
- **Фаза 4**: Resource-Linked

#### 5. Стабилизация
- **Описание**: Защита от спекуляций

- **Попап**: Детальные механизмы

- **Центр**: Карта с выделенными регионами

### Регион 1: Средняя Азия (Кризис водных ресурсов)

#### Проблема:
- Кризис водных ресурсов
- Потери воды в инфраструктуре
- Недостаток средств на модернизацию
- Дефицит энергии и других ресурсов

#### Решение:
- **Реконструкция насосных станций**:
  - Pumping Station No.2 (Джизак) - $7,760,600
  - Korovulbozor (Бухара) - $6,189,700
  - Kuyumazar (Бухара) - $11,965,400
  - Amu-Bukhara-1 (Бухара) - $9,490,100
- **Строительство водоочистных станций**
- **Оптимизация ресурсов и бюджетов**

#### Мегапроект: Восстановление Аральского моря
- **Описание**: Перенаправление рек с сезонными паводками
- **Масштаб**: Региональный мегапроект
- **Участники**: Правительства стран, международные организации
- **Этапы**: Концепция → Проектирование → Реализация
- **Попап**:
  - Детальное описание проекта
  - Технические решения
  - Экологическое воздействие
  - Финансирование
  - Временные рамки

### Регион 2: Израиль (Дефицит бюджетных средств)

#### Проблема:
- Дефицит бюджетных средств
- Отказ от анализа и контроля питьевой воды
- Отказ от анализа морской воды
- Недостаток постоянного мониторинга

#### Решение:
- **Унифицированные датчики постоянного мониторинга**:
  - IoT датчики с прямым хэшированием в блокчейн
  - Системы аналитики и расчетов
  - Оптимизация процессов
- **Продвижение инициатив**:
  - Проекты и продукты в ProjectHUB
  - Образовательные программы
  - Партнерства с местными организациями

#### Попап:
- Детальное описание проблем
- Технические решения
- План внедрения
- Финансирование
- Ожидаемые результаты

### Визуализация:
- Карта с подсветкой регионов
- Клик на регион → попап с детальной информацией
- Анимация "решения" (переход от красного к зеленому)

## Навигация

### Варианты навигации:
1. **Scroll-based**: Плавная прокрутка с привязкой к экранам
2. **Button-based**: Кнопки "Далее" / "Назад" между экранами
3. **Menu-based**: Боковое меню с якорными ссылками
4. **Hybrid**: Комбинация всех методов

### Рекомендация:
- Scroll-based как основной метод
- Боковое меню для быстрой навигации
- Кнопки "Далее" для направляющего потока
